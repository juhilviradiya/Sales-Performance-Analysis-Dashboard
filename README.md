# Sales Performance Analysis Dashboard

## 📌 Project Overview

This project focuses on analyzing sales data and creating a visual dashboard using Python, Pandas, and Matplotlib.

The dashboard helps understand sales performance through different visualizations.

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Excel

## 📊 Dashboard Visualizations

1. **Monthly Revenue Analysis** – Shows monthly revenue trends using a line chart.
2. **Region-wise Revenue Analysis** – Compares revenue across different regions using a bar chart.
3. **Top 10 Products by Profit** – Identifies the top 10 profitable products using a horizontal bar chart.
4. **Sales Channel Revenue Distribution** – Displays revenue contribution by sales channel using a pie chart.
